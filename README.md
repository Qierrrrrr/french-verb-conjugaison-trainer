# ConjuTrain - 法语动词变位练习器

*French Verb Conjugation Trainer*

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/Conjugaison-trainer)

一个优雅的法语动词变位在线练习工具，帮助学习者掌握法语动词的各种时态变位。

---

## 📖 使用说明

### 界面概览

页面顶部的 **Conjugaison française** 大标题下方是控制区域：
- 左上角：语言切换按钮（点击循环切换：简体中文 ↔ English ↔ Français）
- 右上角：深色/浅色模式切换按钮（○ 浅色模式 / ● 深色模式）

页面分为两个主要标签页：**练习** 和 **历史记录**

---

### 1. 选择时态

在"选择时态"卡片中，点击各个时态标签即可选中/取消选中。

**支持的时态：**
| 缩写 | 完整名称 | 说明 |
|------|----------|------|
| Prés. | Présent | 现在时 |
| Imp. | Imparfait | 未完成过去时 |
| Passé S. | Passé simple | 简单过去时 |
| Subj. | Subjonctif | 虚拟式 |
| Cond. | Conditionnel | 条件式 |
| Part.P. | Participe passé | 过去分词 |
| Part.Pr. | Participe présent | 现在分词 |

**注意：**
- 至少需要选择一个时态才能开始练习
- 选择多个时态时，系统会随机抽取进行练习

---

### 2. 选择动词

在"选择动词"卡片中可以：
- **点击单个动词**：选中和取消该动词
- **点击"全选/取消"按钮**：在全部选中和仅保留一个之间切换

**注意：**
- 至少需要保留一个选中的动词
- 已选的动词会高亮显示（蓝色背景）
- 动词列表支持展开/收起，点击标题即可切换

---

### 3. 题目数量

拖动滑块可以调整每次练习的题目数量，范围为 **3-20 题**。

---

### 4. 练习模式

在"练习模式"卡片中选择：

#### 随机模式
- 随机从选定的时态和动词中抽取题目
- 无时间限制，可以慢慢思考

#### 限时模式
- 每道题目有独立的时间限制
- 拖动滑块可调整每题时限（10-120秒）
- **时间到后会跳转下一题**，届时系统自动判断输入内容对错，并留出1秒时间查看结果与正确答案（如果看得够快）

---

### 5. 开始练习

点击 **"开始练习 →"** 按钮进入练习界面。

#### 练习界面说明

- **顶部进度条**：显示当前进度（如 "练习 3 共 8 题"）和正确率百分比
- **倒计时线**（仅限时模式）：显示剩余时间，进度条逐渐缩短
- **动词和时态**：显示当前需要变位的动词原形和时态
- **特殊字符工具栏**：点击输入框后，按 Esc 键可打开特殊字符面板，包含：
  - `à â ç é è ê ë î ï ô œ ù û ü`
  - 使用方向键选择，Enter 键插入，Esc 键关闭

#### 输入与核对

1. **正常输入**：在输入框中输入变位形式
2. **核对答案**：点击"核对答案"按钮或按 Enter 键
   - 正确答案显示绿色边框和勾选标记
   - 错误答案显示红色边框和正确答案提示
3. **跳过题目**：点击"跳过 →"跳过当前题目（计为错误）

#### 键盘快捷键

| 按键 | 功能 |
|------|------|
| Enter | 核对答案 / 进入下一题 |
| Esc | 打开/关闭特殊字符面板 |
| ↑ ↓ ← → | 调整光标在字母间的位置；在特殊字符面板中导航 |
| Tab | 在人称输入框之间跳转 |

---

### 6. 查看结果

完成所有题目后显示结果页面：

- **正确率百分比**：根据成绩显示不同颜色（金色/绿色/蓝色/红色）
- **统计数据**：总题数、全对数量、出错数量
- **练本次错题**（如有）：快速重新练习本次错误题目

**操作按钮：**
- **保存练习**：保存到历史记录（可手动删除）
- **再练一次**：重新开始相同设置的练习

---

### 7. 历史记录

点击"历史记录"标签页查看练习历史。

#### 错题本

- 自动整理**手动保存过的**所有做错的题目
- 标注学习状态：
  - **待复习**（红色）：尚未连续答对
  - **加强中**（橙色）：连续答对1次
  - **已掌握**（绿色）：连续答对2次以上
- 点击"练习待复习"可针对错题进行强化训练

#### 练习记录

- 查看所有保存的练习记录
- 点击记录可展开查看详细答题情况
- **删除记录**：鼠标悬停时显示删除按钮

---

### 8. 界面定制

#### 深色/浅色模式

点击右上角的 ○/● 按钮切换：
- ○ 浅色模式（默认）
- ● 深色模式

偏好设置会自动保存。

#### 语言切换

点击左上角语言按钮循环切换：
- 简体中文
- English
- Français

---

## ⚠️ 注意事项

1. **数据存储**：所有数据保存在浏览器本地存储（localStorage）中，清除浏览器数据会导致历史记录丢失
2. **限时模式**：时间到会自动跳转到下一题，请注意时间管理
3. **特殊字符**：法语特殊字符（如 é, è, ê, ë, ç, œ 等）是变位的关键，请熟练使用特殊字符工具栏
4. **答案判定**：系统使用不区分大小写、忽略首尾空格的严格匹配
5. **历史记录上限**：最多保存50条记录，超出后自动删除最旧的记录

---

## 🎯 学习建议

1. **循序渐进**：建议先从 Présent（现在时）开始，掌握后再学习其他时态
2. **针对性练习**：利用错题本功能，针对性地强化薄弱环节
3. **限时训练**：熟练后可尝试限时模式，提高反应速度和准确性
4. **坚持练习**：动词变位需要大量重复练习才能形成肌肉记忆
